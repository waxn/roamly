# Quick notes ("what I did today")

_Read when: Quick notes on the map, the notes API, the evening reminder on Android._

**Stored on the day's `JournalEntry` (`quick_note`, migration `0117`).** There is no separate model: a quick note is a field of that day's one journal entry, so Journals shows it on the day (detail, list, search, Ask, the recap all read it). **The reverse is deliberately not true:** the notes endpoints and the map only ever return `quick_note`, never the journal's title or body. That one-way rule is what the user asked for ("notes display in the journal but journal posts don't display in notes"); `test_list_never_includes_journal_body` pins it.

**API** (`views.quick_notes_list_api` / `views.quick_note_api`):
- `GET /api/notes/?start=YYYY-MM-DD&end=YYYY-MM-DD` — days with a non-empty note, newest first, both bounds optional, capped at 400.
- `GET /api/notes/<date>/` — `{date, note, updated_at}`; a day with nothing returns an empty note, not a 404.
- `POST /api/notes/<date>/` `{"note": "..."}` — upsert (trimmed, ≤2000 chars). `@csrf_exempt` + `_require_api_intent` like the other app-called journal endpoints. **An empty note clears it, and deletes the entry when the note was all it held** (`_journal_entry_is_blank`: no title/body/mood/favorite/location/pin/photos; auto-filled weather does not count), so jotting and un-jotting leaves no empty day in Journals.
- `journal_save_api` also accepts `quick_note`, so the Journals editor can change it.

The date is always the **client's** local calendar day; the server does no timezone conversion for notes.

**Web map (`map.html`).** A pill in the **top-centre column** (`.map-top-center`, which also takes the load-more prompt when Map layout puts it up top, so the two stack instead of overlapping; top-right at ≤900px, shrunk to "today" at ≤600px) **follows the map's range** (`readSpan()`, from `rangeStepInfo()`): a one-day range (the hour options, Last 24 hours, or a day stepped to with ‹ ›) reads "<day> · <first line>" or "what did you do today / yesterday / on Nov 20?", and the composer writes to that day; a range of 2 to 31 days reads "n daily notes" and the composer opens on today when the range reaches it, else the range's last day; All time and anything longer than 31 days hide the pill. Unsaved typing keeps its day when the range moves. It opens a panel with a composer (save button, ⌘/Ctrl+Enter; emptying an existing note turns the button into **remove**) and the notes for the days the map's range covers, fetched via `ROAMLY_MAP_HOOKS.onRangeChanged` / `currentRangeDays()` (see map.md Range stepping), so the ‹ › arrows walk notes along with the track. Each item can **show day** (exact single-day range, which the arrows then step a day at a time) or **edit** (loads it into the composer with "back to <the range's day>"); clicking the text unclamps it. The list shows at most 60 (the rest are in Journals). An unsaved draft survives a reload in `roamly_note_draft` (`{date, text}`). Past midnight, reopening the panel moves "today" on. The pill and panel are in every Appearance component's map-surface `:is(...)` list, and the themes that float the nav (Pebble, Jelly, Tidepool) offset `.map-top-center` the same way as the sidebar.

**Journals (`journals.html`).** The editor shows the note as its own field (**quick note · shows on the map**, an auto-growing line between weather and the body), saved with the rest of the entry through `journal_save_api`. Entry cards show it as a `✎` line above the body snippet (the snippet is skipped when it is the same text, which the search API produces for a note-only day).

**Android map (`ui/notes/`).** Under the time-range pill (top-left) sits **`QuickNotePill`** ("What did you do today?" / "Today · <first line>", `+n` for other days in range); it opens **`QuickNoteSheet`**, a full-height `ModalBottomSheet` with the composer (Save / Remove) and the notes for the map's range, each with **Show day** (`MapViewModel.navigateToDate`) and **Edit**. `QuickNotesViewModel` is **Activity-scoped and built eagerly** in `RoamlyNavHost` (unlike the tab VMs it loads nothing in `init`; it waits for `setRange`, which MapScreen calls with `MapUiState.rangeDays()` whenever the range changes). The time pill also got **‹ ›** (`MapViewModel.stepRange`, same rule as the web: a live period steps back into the custom range before it, and stepping forward onto today returns to the live period, `stepOrigin` remembering which; `TimePeriod.stepDays`, 6h/24h step a day). `DateRange.label` is now human ("Sat, Nov 22", "Nov 16 – Nov 22").

**Android Journals.** The editor has a **Quick note** field ("Shows on the map") sent as `quick_note` with the rest of the entry; `JournalSaveRequest.quickNote` is nullable so Gson drops it when unset and older callers can't clear it. The recent list falls back to the note when the body snippet is empty.

**Evening reminder (Android, `notes/QuickNoteReminder.kt`).** One **inexact `setAndAllowWhileIdle` alarm** a day (no exact-alarm permission; still fires in Doze), default **19:30**, set in Settings → **Daily note** (toggle + Material3 `TimePicker`; turning it on asks for `POST_NOTIFICATIONS` on 13+). Prefs `note_reminder_enabled` (default **on**) / `note_reminder_minute`. Armed by `scheduleFromPrefs` from `RoamlyApp.onCreate`, `BootReceiver` (not the locked boot: DataStore is credential-protected), `RoamlyNavHost` once signed in, Settings changes, and by **`QuickNoteReminderReceiver` itself each time it fires** (re-arm tomorrow first, then post). It posts on channel `roamly_daily_note` **only if today has no note** (`GET /api/notes/<today>/`, 8s timeout; a failed check posts anyway). `isWanted` = signed in + enabled + **not Simple Mode** (a Simple Mode phone is tracked, not kept). Tapping opens `MainActivity` with `open_quick_note`, which raises `QuickNoteLaunch` (the `IncomingShare` pattern): `RoamlyNavHost` brings the Map tab forward and `MapScreen` opens the sheet with the cursor in the box. Saving today's note also dismisses a posted reminder. `nextTrigger` keeps the wall-clock time across DST (`QuickNoteReminderTest`).

**Backup:** `_build_journals_data` exports `quick_note`, restore reads it; `meta.version` 26.
