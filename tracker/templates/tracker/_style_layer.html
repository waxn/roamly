{% load static %}{% comment %} Style layer: optional alternative visual styles on top of Field Journal. Field Journal (base.html's own CSS) is the default and stays untouched. A style is one CSS file (every rule scoped under html[data-style=""]) plus an optional JS file for behaviour (springs, WebGL, split-flap digits…). Only the chosen style's files are fetched, and they are document.write()n here in so they are parser-inserted and render-blocking: no flash of the default style on load. Choice lives in localStorage `roamly_style`; a `?rly_style=` query param sets it too (so a preview link can be shared), and Alt+Shift+S cycles through every style. {% endcomment %}
