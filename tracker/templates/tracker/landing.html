🗺️

interactive maps

visualize your location history with maplibre gl and postgis vector tiles. fast rendering even with millions of points.

📊

travel statistics

distance traveled, countries and cities visited, time spent at each place — all calculated automatically from your data.

✈️

trip management

organize locations into named trips with places. roamly tracks how long you spent at each waypoint using gps proximity.

📍

visit analytics

see every city, state, and country you've visited with visit counts, first/last seen dates, and total time spent.

🔒

self-hosted & private

runs entirely on your server. no telemetry, no tracking, no data sharing. the only external call is openstreetmap for geocoding.

📱

owntracks compatible

native support for owntracks http mode on ios and android. or use any app that can send http post requests.

📥

import & export

full data portability — export as csv, gpx, or json backup. import from gpx files, csv data, or restore from backup.

🌍

reverse geocoding

coordinates are automatically converted to city, state, and country names using openstreetmap nominatim.

📱

multi-device & pwa

track multiple devices with separate api keys. installable as a progressive web app with dark and light themes.

up and running in 2 minutes

docker compose handles everything — database, migrations, and the web server

1

clone & start

git clone https://github.com/waxn/roamly.git
cd roamly
docker compose up -d
2

create an account

open localhost:8001, sign up, and create an api key in settings.

3

connect owntracks

install owntracks on your phone, set it to http mode, and point it at your server's /api/push/ endpoint with your api key.

4

start exploring

your locations appear on the map in real time. check stats, create trips, and explore your travel history.
