Field notes on ownership

three principles, no asterisks
N. 01

It never phones home

Your points live in your Postgres, your Docker volume, your S3 bucket. There is no telemetry, no analytics beacon, no third party in the loop — the only server Roamly talks to is the one you started.

N. 02

Offline where it counts

US points reverse-geocode against bundled Census boundaries with point-in-polygon lookups — no Google, no per-point API call, no rate limit. A town resolves to the place that contains it, not the nearest guess.

N. 03

Built to run for years

Gated distance that ignores GPS jitter, nightly stat snapshots, Doze-proof capture on Android, idempotent backups. Boring in the way infrastructure should be — it just keeps logging.

02 — What's in the box

Not another SaaS map widget

Roamly is a full Django app you self-host — map, journals, adventures, pals, diagnostics, an AI you bring yourself, and a native Android client, all in one place.

Map

Speed-gradient tracks, density heatmaps, a day-by-day replay animation, and a "scratch map" of every country and US state you've set foot in. Vector tiles at scale on PostGIS, classic mode on SQLite.

Stats & visits

Distance is jitter-resistant — resampled, movement-gated, teleport-rejected — not a raw point-to-point sum. Dwell time per place is computed the same careful way, then cached in a nightly snapshot for instant loads.

Search by place name, date phrase, or radius around a point. Define your own named geofences and get full stats back — top cities, dwell time, a sample track — for each one.

03 — From zero to logging

Live in about two minutes

Docker Compose brings up the database, migrations, and web app. Create an API key, point GPSLogger at your instance, watch points appear.

  1. Grab & start

    Pull the prebuilt waxn/roamly image. PostGIS and migrations run automatically.

    curl -O https://raw.githubusercontent.com/waxn/roamly/main/docker-compose.yml
    docker compose up -d

  2. Sign up & API key

    Open your instance, create an account, then Settings → API Keys for your phone.

  3. Push locations

    GPSLogger custom URL or OwnTracks → /api/push/ with your key. Garmin/Strava exports work via CSV import too.

    curl -X POST localhost:8001/api/push/ \ -H "Authorization: Bearer YOUR_KEY" \ -d '{"device_id":"phone","latitude":45.5,"longitude":-122.6}'

  4. Explore

    Map your history, run geocoding, check visits dwell time, log an adventure, invite pals.

  5. Staying current

    Updates are just a pull and restart — no git clone, no rebuild.

    docker compose pull && docker compose up -d
