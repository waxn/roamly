what you get

everything, nothing you don't need

no saas, no subscriptions, no data handed to a third party. just your gps history on a server you run.

01
interactive map

maplibre gl with postgis vector tiles. renders millions of points fast. heatmap + dot layers, time range filtering, trip trails.

02
travel statistics

total distance, countries and cities visited, time spent at each place — all computed on-the-fly from your raw location data.

03
adventures

log any outing — a 7-hour bike ride, a hike, a road trip. mark locations with radius zones, add timeline notes with photos, and share a public link.

04
visit analytics

every city, state, and country you've visited — with visit counts, first/last seen dates, and total time spent. yearly overview with period comparisons.

05
self-hosted & private

runs on your own hardware. no tracking, no analytics, no data ever leaves your server except a nominatim geocode call for place names.

06
gpslogger & owntracks

built for gpslogger on android — free, open-source, battery-friendly. also works with owntracks on ios and android, or any plain http post from curl, python, home assistant, tasker.

07
import & export

csv, gpx 1.1, or full json backup — import from any source, export to anything. your data in open formats, always.

08
automatic s3 backups

schedule backups to any s3-compatible storage — backblaze b2, cloudflare r2, minio, aws. set retention and forget about it.

09
reverse geocoding

coordinates become city/state/country names via openstreetmap nominatim with spatial clustering to stay under rate limits.

10
multi-device + pwa

separate api keys per device, individual tracking on a shared account. installable as a pwa on ios and android. dark and light themes built in.

setup

running in about two minutes

docker compose handles the database, migrations, and server. once it's up, point gpslogger at your endpoint and you're tracking.

1

clone and start

git clone the repo, cd roamly, docker compose up -d. that's it — postgis and migrations are automatic.

2

create your account

open localhost:8001, sign up, then go to settings and create an api key for your phone.

3

connect gpslogger

enable "log to custom url", point it at /api/push/ with your api key in the json body, send a test location.

4

you're live

locations appear on the map as they arrive. explore stats, log adventures, run geocoding to get city names.
