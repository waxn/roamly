a native android app, built in

sign in with an api key — it stays signed in forever, even after the web session expires. a foreground tracking service survives reboots, doze, and battery saver, with live-tunable interval, gps priority, movement distance, and accuracy. points cache in room and upload offline-first, plus a local csv mirror. browse your map, stats, adventures, and pals from your phone.

docker on your metal

sqlite for simple setups, postgresql + postgis when you want tiles at scale. schedule s3 backups (data + images), import csv/gpx/google takeout/owntracks json, export everything. nominatim geocoding is the only outbound call for place names.

docker compose s3 backups pwa installable
import anything

csv, gpx 1.0/1.1, google takeout location history, owntracks json — assign to a device on import.

reverse geocoding

background nominatim job clusters coordinates first to respect rate limits, then fills city/state/country.

api keys per device

bearer token or json body on /api/push/ — gpslogger, owntracks, curl, home assistant.

data table & exports

sort and filter every location row, jump to a point on the map, export csv or gpx, download a full json backup and restore later.

tunable map display

heatmap intensity, dot size, line gap threshold, detail zoom level, cluster radius, and per-device colors — all stored in local preferences.

setup

live in about two minutes

docker compose brings up the database, migrations, and web app. create an api key, point gpslogger at your instance, watch points appear.

1

grab & start

pull the prebuilt waxn/roamly image with docker compose up -d. postgis and migrations run automatically. updates are just docker compose pull && docker compose up -d — no git pull, no rebuild.

2

sign up & api key

open your instance, create an account, then settings → api keys for your phone.

3

push locations

gpslogger custom url or owntracks → /api/push/ with your key. garmin/strava exports work via csv import too.

4

explore

map your history, run geocoding, check visits dwell time, log an adventure, invite pals.

~/roamly
# grab compose file & start (pulls waxn/roamly image)

# later, to update: no git pull needed

# push a test fix
curl -X POST localhost:8001/api/push/ \
-H "Authorization: Bearer YOUR_KEY" \

{"status":"ok"}
