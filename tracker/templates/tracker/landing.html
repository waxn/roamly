quick start setup

get roamly running in minutes

docker (recommended)

git clone https://github.com/waxn/roamly.git
cd roamly
docker-compose up -d

access at localhost:8001

manual installation

  1. Install Python 3.12+ and PostgreSQL
  2. pip install -r requirements.txt
  3. Set DATABASE_URL environment variable
  4. python manage.py migrate
  5. python manage.py createsuperuser
  6. python manage.py runserver or use gunicorn

Optional: Install PostGIS for advanced spatial features. view full docs →
