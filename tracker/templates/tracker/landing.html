setup

Live in about two minutes

Docker Compose brings up the database, migrations, and web app. Create an API key, point GPSLogger at your instance, watch points appear.

  1. Grab & start

    Pull the prebuilt waxn/roamly image. PostGIS and migrations run automatically.

    curl -O https://raw.githubusercontent.com/waxn/roamly/main/docker-compose.yml
    docker compose up -d

  2. Sign up & API key

    Open your instance, create an account, then Settings → API Keys for your phone.

  3. Push locations

    GPSLogger custom URL or OwnTracks → /api/push/ with your key. Garmin/Strava exports work via CSV import too.

    curl -X POST localhost:8001/api/push/ \ -H "Authorization: Bearer YOUR_KEY" \ -d '{"device_id":"phone","latitude":45.5,"longitude":-122.6}'

  4. Explore

    Map your history, run geocoding, check visits dwell time, log an adventure, invite pals.

  5. Staying current

    Updates are just a pull and restart — no git clone, no rebuild.

    docker compose pull && docker compose up -d

why self-host

Your trail. Your server. Your rules.

Roamly is free and open source, with no telemetry and no account lock-in. It's the software available in the project repository — read it, change it, run it however you like.

  • Nominatim reverse-geocoding is the only outbound call the app ever makes, and only for place names.
  • Docker on your own metal — SQLite for simple setups, PostgreSQL + PostGIS when you want vector tiles at scale.
  • Scheduled S3 backups for data and photos; import from CSV, GPX, Google Takeout, or OwnTracks JSON at any time.
  • Every API key is scoped per device, with bearer-token auth for GPSLogger, OwnTracks, Home Assistant, or plain curl.
