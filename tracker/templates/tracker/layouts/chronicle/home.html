Why the old thumbnails were blank (and what is different here): * base.html loads maplibre-gl.js AFTER the content block, so inline page scripts that initialised a map at parse time found `maplibregl` undefined. This page boots from extra_js (after the library) and waits for it anyway. * A map created inside a 0px / display:none box never gets a size. Maps here start only when the tile is on screen (IntersectionObserver) and are resize()d whenever the box changes. * Tile URLs were hard-coded without the instance CARTO key and ignored the user's chosen basemap. This page uses the server list (keys included). * A raster style whose tiles all fail still fires `idle`, so the old code revealed an empty canvas. Here a map with only failed tiles shows the route drawn flat on a neutral surface, with a Retry.
