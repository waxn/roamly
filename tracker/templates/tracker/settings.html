API Usage

Push location data using any HTTP client. Example: 

# Standard format
curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/push/ \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"device_id": "my-phone", "latitude": 45.5, "longitude": -122.6}'

# OwnTracks format (auto-detected)
curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/push/ \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"_type": "location", "lat": 45.5, "lon": -122.6, "tst": 1234567890, "tid": "phone"}'
